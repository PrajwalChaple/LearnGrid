# Security Policy

Below is the list of project versions and their support status for security updates. 

| Version | Supported          |
| ------- | ------------------ |
| v1.x.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security-related issues in LearnGrid, please do not report them through public issues.

Instead, please report the vulnerability by contacting the repository owner directly.

1. Email: [Your Email Here / Or GitHub Direct Message]
2. Include a detailed description of the vulnerability and steps to reproduce it.

We take all security vulnerabilities seriously and will respond to reports as quickly as possible (usually within 48 hours). If a vulnerability is confirmed, we will release a patch immediately and mention the reporter in the release notes.
